# InovaPro App

MVP mobile-first do ecossistema digital da **InovaPro Systems**.

**Conectando você ao mundo.**

Princípio: **Problema primeiro. Tecnologia depois. Resultado sempre.**

## Rodar localmente

```bash
npm install
npm run dev
```

- Interface da NOVA

- Identidade visual InovaPro

Integrações reais de IA, pagamentos, autenticação e diagnósticos serão adicionadas progressivamente. A V1 não simula integrações como se estivessem ativas.
